# RECHIEL-LAPUT
## Web-Based Service Request and Tracking System

### Project Description
The Service Request and Tracking System is a web-based application designed to help users submit service requests and monitor their status. It helps organize requests and makes tracking easier for users and personnel.

### Main Features
- User Login and Logout
- Submit Service Requests
- View and Track Requests
- Manage Request Status
- Dashboard for Monitoring Requests

### Technologies Used
- HTML
- CSS
- JavaScript
- Supabase
- GitHub Pages
